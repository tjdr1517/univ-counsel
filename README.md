# 담다 — 대입 상담 기록

교사와 학생이 상담 기록과 입시 자료를 안전하게 공유하는 Sites 웹 애플리케이션입니다.

## 주요 구성

- 일반 아이디와 비밀번호를 사용하는 자체 로그인
- 학생 가입 후 담당 교사 승인
- 우리 반 학생 번호 관리
- 상담 참여자만 열람 가능한 상담 기록
- 상담 내용과 첨부파일 중심의 상담 기록
- 대학·학과·전형·수능 최저·메모를 관리하는 별도 관심 대학 목록
- 관심 대학 내신 등급·2023~2025 커트라인·지망 순위 관리
- 공지 및 상담 기록 파일 첨부
- Cloudflare D1 데이터베이스와 R2 파일 저장소

교사 계정은 운영 환경의 `TEACHER_IDS` 허용 목록과 `TEACHER_SETUP_CODE`를 사용해 만듭니다.
